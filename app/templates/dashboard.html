ABOUT THE MODEL

Explainable anomaly detection

AERIS uses statistical and machine-learning techniques to identify telemetry observations that differ from the learned behavior of the supplied dataset.

01
Data validation Uploaded telemetry is checked for usable numerical features and missing values.
02
Feature preparation Relevant numerical measurements are prepared for statistical or ML analysis.
03
Anomaly scoring The selected model assigns observations an anomaly indication based on learned data patterns.
